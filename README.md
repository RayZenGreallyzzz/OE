# OE — Orvetra Engine

**OE Native 0.2 Alpha** — собственный экспериментальный нативный 3D-редактор для Android (Java UI + C++17/OpenGL ES 3.0). **Без браузера и без Godot**. Цель — лёгкий редактор с сенсорным управлением для планшетов с 4 ГБ ОЗУ.

- **[Android: инструкции, сборка APK и возможности](android/README.md)**
- **[GitHub Actions: скачать debug APK после успешной сборки](../../actions/workflows/android-apk.yml)**
- **[Исходный код Android-рендерера](android/src/main/cpp/native_engine.cpp)**

### Развитие OE

На Android сейчас предусмотрены простые 3D-здания, движение камеры, выбор и трансформация объектов, сохранение JSON внутри приложения и рендеринг по запросу (когда сцена не меняется, кадры не перерисовываются). Импорт реальных GLB, материалы, физика и перенос скриптов Godot — **следующие этапы**; утверждать, что все функции уже работают на реальном планшете, пока рано.

**Проект ORVETHRA на Godot остаётся отдельным и не изменяется.**

## Архивный браузерный прототип — WebGL2 Alpha 0.1

Ниже историческая документация первой веб-версии, которая сохранена для экспериментов. Она **не является Android OE Native**.

**OE** — собственный экспериментальный 3D-движок и редактор мира для фэнтезийной игры «Орветра». Цель — иметь рабочий редактор с подходом к сценам и объектам, знакомым по Unreal, но ориентированный на маломощные устройства.

## Что уже работает в Alpha 0.1

- Полностью собственный рендерер на **WebGL2** без Three.js, Babylon.js, npm и игровых движков.
- 3D-вид со светом, перспективой и вращением/масштабированием камеры (мышь и мультитач).
- Тестовый квартал: **таверна, кузница, аукцион**, дорога и фонари.
- Иерархия объектов, выбор объекта, инспектор имени, позиции, вращения Y, масштаба и цвета.
- Добавление простых примитивов и зданий.
- Сохранение проекта в localStorage и импорт/экспорт сцены в **JSON**.
- Режим **«Играть»**: управление тестовым персонажем с клавиатуры WASD/стрелками и экранными кнопками.

## Как запустить

Откройте страницу `index.html` в браузере с WebGL2. Надёжнее запускать через локальный HTTP-сервер:

```bash
python -m http.server 8080
```

Перейдите на `http://localhost:8080`. Для планшета в той же Wi-Fi сети откройте `http://IP_КОМПЬЮТЕРА:8080` (сервер может потребовать настройку брандмауэра).

**Проверка синтаксиса:** `node --check src/engine.js && node --check src/editor.js`.

## Управление

- Перетаскивание по 3D-виду — вращать камеру.
- Колёсико мыши или два пальца — приближение/отдаление.
- Клик по объекту или выбор в иерархии — выделить.
- В режиме игры: WASD / стрелки, на планшете — экранные кнопки.
- Сохранить — в памяти браузера; экспорт — скачать JSON; импорт — открыть JSON.

## Ограничения MVP

Это **не готовый аналог Unreal Engine**: пока нет импорта GLB/FBX, скининга, анимации, текстур PBR, теней, физического движка, навмеша, сетевой игры, APK-сборки и полноценных редакторских gizmo. Простые здания — примитивы для демонстрации структуры сцены. Поддержка WebGL2 зависит от браузера/планшета, FPS не гарантируется.
