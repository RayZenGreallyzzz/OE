# OE Native 0.3 Alpha — Android, без ПК

**OE** — нативный экспериментальный 3D-редактор на Android, написанный на C++17/OpenGL ES 3.0 с сенсорным интерфейсом Java. Браузер и Godot для работы OE не нужны. ORVETHRA на Godot хранится в другом репозитории и не изменяется.

## Установка на планшет

1. Откройте [OE Android APK в GitHub Actions](../../actions/workflows/android-apk.yml) со своего планшета.
2. Выберите последний **успешный** запуск.
3. В разделе **Artifacts** скачайте `OE-Android-arm64-debug`; распакуйте ZIP на планшете и установите `android-debug.apk`.
4. Если Android запросит разрешение, разрешите установку APK из используемого файлового менеджера.

APK создан для Android 8+ с 64-битным ARM-процессором и поддержкой OpenGL ES 3.0; проект настроен на Android SDK 35, Android 15 не обязателен.

## Первая загрузка GLB без компьютера

1. Через браузер планшета скачайте **обычный .glb-файл**, например из [папки ORVETHRA/GLB](https://github.com/RayZenGreallyzzz/ORVETHRA/tree/main/assets/catacombs). Не скачивайте скриншот или ZIP вместо GLB.
2. Запустите **OE Editor** и нажмите **«Импорт GLB»**.
3. В стандартном окне Android **Файлы** откройте скачанную модель из «Загрузки».
4. Сцена создаст объект **Модель GLB**; его можно выбрать, перемещать, вращать и масштабировать.
5. Нажмите **Сохранить** — сцена и локально скопированная модель сохраняются во внутренней памяти OE; **Загрузить** восстанавливает их без компьютера.

**Формат первого этапа**: бинарный **glTF 2.0 GLB** со статической, несжатой треугольной геометрией; объекты и иерархия узлов с матрицами/TRS, материал `baseColorFactor`. Нормали пересчитываются по граням, модель нормализуется примерно к размеру 6 метров. Пока **нет** текстур, UV, скелетной анимации, морфов, прозрачности, Draco/meshopt, PBR, FBX, VRM, скриптов или сцен Godot. Это проверка загрузки реальных 3D-мешей и поведения GPU, не финальное качество графики.

Ограничения из-за 4 ГБ ОЗУ: **24 МБ на один GLB, до 90 000 треугольников на файл, 12 уникальных моделей и 300 объектов на сцену**. Несовместимые или превышающие лимит модели показывают ошибку, не загружаются.

## Работа и диагностика

- 1 палец: вращение камеры; 2 пальца: приближение.
- Касание модели: выбор; кнопки снизу: X/Z перемещение, поворот 15°, размер ±10%.
- Кнопка «Объекты»: иерархия/список сцены.
- Проект хранится только на планшете в приватной памяти приложения.
- Редактор использует `GLSurfaceView.RENDERMODE_WHEN_DIRTY` и останавливает перерисовку при отсутствии действий; импорты выполняются в отдельном потоке с загрузкой в OpenGL на графическом потоке.
- Для сравнения с Godot проверьте **есть ли писк при неподвижной камере**, а затем **во время вращения камеры над загруженным GLB**. Работа с текстурами позже может давать другую нагрузку; гарантировать отсутствие писка нельзя.

## Собственная сборка

CI: [Android APK Actions](../../actions/workflows/android-apk.yml). Локально с Gradle 8.9, JDK 17, Android SDK 35, NDK 26.3 и CMake 3.22.1:

```sh
gradle :android:assembleDebug
```

Результат: `android/build/outputs/apk/debug/android-debug.apk`.
