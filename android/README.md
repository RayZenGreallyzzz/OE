# OE Native 0.4 Alpha — Android, без компьютера

Собственный нативный редактор Orvetra Engine (Java + C++17/OpenGL ES 3.0). Устанавливается на планшет APK, не требует браузера или Godot. Игра ORVETHRA в отдельном репозитории не меняется.

## Новое в 0.4

- **Карта 1024 × 1024 метра**, разбитая на квадраты по 64 метра. Рендерер рисует только участки вокруг камеры (не всю карту разом).
- **Пять точек перемещения:** город (0,0), волшебный лес (256,0), древние руины (-256,-64), катакомбы (16,-256) и дикие земли (32,256). Сейчас это зоны с разным цветом грунта, а не готовые детализированные локации.
- **Новая сцена → Пустая карта:** удаляет все здания, объекты, демонстрационные дороги и выделение; сам ландшафт остаётся.
- **Новая сцена → Восстановить демонстрационный город:** возвращает квартал (не смешивает его с текущими объектами).
- **Удалить выбранное:** выбери объект на карте или в списке и нажми кнопку удаления. Требуется подтверждение.
- **Добавить здание:** нажми «+ Таверна», «+ Кузница», «+ Аукцион» или «+ Фонарь», затем **коснись свободной земли на карте**, чтобы определить место. Случайное наложение зданий блокируется. «Отмена» отменяет размещение.
- **Два пальца:** двигать карту и приближать/отдалять. Один палец — вращать камеру. «Локации» — быстро прыгнуть в другую часть большого мира.
- JSON сохраняет здания и флаг демонстрационных дорог. При пустой сцене повторное открытие 3D-окна не должно восстанавливать демо автоматически.

## Загрузка моделей без ПК

Кнопка «Импорт GLB» открывает Android «Файлы». Скачай модель **.glb** с телефона или планшета, выбери её, затем коснись места на карте. Сцена и модель сохраняются локально; кнопка «Загрузить» восстанавливает их. Полный формат пока не реализован: только **glTF 2.0 GLB** со статической *несжатой* треугольной геометрией и цветом `baseColorFactor`. Нет текстур, UV/PBR, анимаций, Draco/meshopt, FBX или импортера проектов Godot.

Ограничения тестовой версии для 4 ГБ RAM: **24 МБ на GLB, до 90 000 треугольников на модель, 12 уникальных GLB и максимум 300 объектов**. Предварительно все модели должны проходить проверку формата; некорректные файлы отклоняются.

## Скачать и установить APK с планшета

Открой [GitHub Actions — OE Android APK](../../actions/workflows/android-apk.yml), выбери последний **успешный** запуск, раскрой **Artifacts**, скачай `OE-Android-arm64-debug`, распакуй ZIP и установи `android-debug.apk`.

Целевой формат: **Android / ARM64**, GLES 3.0, API 26+. Это отладочная сборка, не релиз.

## Примечания по производительности

Редактор использует `GLSurfaceView.RENDERMODE_WHEN_DIRTY`: в простое не отправляет новые 3D-кадры, а большую землю отрисовывает только поблизости от камеры. Это снижает лишнюю нагрузку, но реальное поведение GPU/дросселей необходимо проверить на самом устройстве — отсутствие писка не гарантировано, особенно с тяжёлыми GLB.

## Сборка из исходников

Gradle 8.9, JDK 17, SDK 35, NDK 26.3, CMake 3.22.1: `gradle :android:assembleDebug`. APK: `android/build/outputs/apk/debug/android-debug.apk`.

## Ещё не реализовано

Настоящий рельеф, стриминг ассетов с диска, редактирование ландшафта, текстуры GLB, материалы PBR, скелетная анимация, физика, сетевой мультиплеер, экспорт независимых игр. Пока это ранний редактор сцен с большим полем для будущих локаций.
